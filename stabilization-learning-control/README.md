# Stabilization Learning Control

镇定学习算法库，提供 M 参数化、策略与价值学习、训练和评价接口。环境由相邻的 stabilization-gym 包提供。

在仓库根目录运行 `python -m pip install -r requirements.txt`，再执行 `python -m stabilization_learning list`。完整用法见[项目指南](../README.md)和[训练指南](../docs/TRAINING.md)。

通用 CLI 与研究 Runner 的算法、采样协议及资源要求不同，具体范围见[实现状态](../docs/IMPLEMENTATION_STATUS.md)。
